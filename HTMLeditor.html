語法參考指南

HTML 基本標籤
標題標籤 (Headings) 從 h1 到 h6，數字越小字體越大。 <h1>主標題</h1>
段落與換行 p 為段落，br 為強制換行。 <p>這是段落</p>
<br>
按鈕元件 (Button) 用於觸發點擊事件。 <button onclick="function()">點擊</button>
表單輸入 (Input) 根據 type 不同有不同功能。 <input type="text"> 文字輸入
<input type="number"> 數字輸入
<input type="range"> 滑桿
<input type="checkbox"> 核取方塊
圖片標籤 (Image) src 為網址，alt 為替代文字。 <img src="url" width="200">
CSS 樣式參考
文字尺寸 (Font Size) 可以使用 px, rem 或百分比。 font-size: 20px;
文字顏色 (Color) 可以使用顏色名稱、HEX 或 RGB。 color: red;
color: #ff0000;
背景設定 (Background) background-color: #f0f0f0;
background-image: url('...');
邊框 (Border) 順序為：寬度 樣式 顏色。 border: 1px solid black;
border-radius: 10px; (圓角)
間距 (Margin & Padding) margin 是外距，padding 是內距。 margin: 20px;
padding: 10px;
定位與排列 (Display) display: block; (區塊)
display: flex; (彈性佈局)
justify-content: center; (置中)
JavaScript 常用指令
視窗彈出 (Alert) alert('訊息內容');
選取元素 (Selector) document.getElementById('id');
修改內容 element.innerHTML = '新內容';
